# Power BI Sales Dashboard

Interactive Power BI dashboard for analysing retail sales performance across revenue, orders, products, customers, and geographic markets.

## Project Overview

This project presents an interactive Power BI dashboard designed to analyse retail sales data and provide a clear view of key business performance indicators and trends.

The dashboard brings together sales, product, customer, and geographic information into an interactive reporting interface.

## Key Performance Indicators

The dashboard includes KPI cards for:

- Total Revenue
- Total Orders
- Total Items Sold
- Average Order Value

## Dashboard Analysis

### Sales Performance
- Monthly Revenue Trend
- Total revenue and order performance
- Average Order Value
- Total items sold

### Product Analysis
- Top 10 Products by Revenue

### Geographic Analysis
- Revenue Share of Top 5 Countries
- Top 5 Customer Markets

### Interactive Filtering
- Date slicer for exploring the dashboard across different time periods

## DAX

DAX was used to create calculated measures for key performance indicators and support the dashboard's analytical calculations.

## Visualisations

- KPI cards
